# TechNova – Frontend

TechNova is a modern, responsive e-commerce web application built with Next.js, TypeScript, and Tailwind CSS.

The frontend provides a seamless shopping experience where users can browse products, manage their shopping cart and wishlist, place orders, and manage their accounts. It also includes a dedicated admin dashboard for managing the e-commerce platform.

## 🚀 Live Demo

**Frontend:** https://technova-frontend-rust.vercel.app

**Backend API:** https://technova-backend-dyrv.onrender.com

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/rutvik-variya/Technova-Frontend.git
```

### 2. Navigate to the project

```bash
cd Technova-Frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root.

```env
NEXT_PUBLIC_API_URL=your_backend_api_url
```

Replace the value with your backend API URL.

### 5. Start the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
